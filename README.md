# SpaceAGORAEDG.jl

Experimental energy-depletion guidance for SpaceAGORA.

This repository is being prepared for its first experimental release. The
implementation and installation instructions will be reviewed in its initial
pull request. No installable release is available from this bootstrap commit.

The scientific scope retains 3 Hz guidance/control and the original physical
limits. Known violations remain reported, and exact journal reproduction is
not established.

The extracted implementation originates in
[SpaceAGORA.jl](https://github.com/Space-FALCON-Lab/SpaceAGORA.jl) and retains its
[MIT license](LICENSE).
